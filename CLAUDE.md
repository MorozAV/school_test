# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статичный сайт с тренировочными тестами для 5 класса (русский язык интерфейса). Нет сборки, зависимостей, линтера и автотестов: каждая страница — один самодостаточный HTML-файл, открывается в браузере напрямую (`file://`) или с любого статического сервера. Шрифты — Google Fonts, всё остальное (CSS, JS, картинки) внутри файла.

## Структура

- `index.html` — главная: карточка на каждый тест (`<article class="test-card">`), счётчик «Доступно N тестов», своя палитра обложки на предмет (`.cover.informatics`, `.cover.history`, дефолт — география) с тёмной темой в `@media (prefers-color-scheme: dark)`.
- `<Предмет>_5_grade/<Тема>.html` — сам тест. Рядом может лежать исходник — учебник в PDF (`History_5_grade/5_klass_Istoria_Drevnego_mira.pdf`), по которому составлены вопросы.

Новый тест = новый HTML в папке предмета + карточка в `index.html` + поправить счётчик тестов (так сделаны все коммиты после первого). Порядок работы — в скилле `new-test` (`.claude/skills/new-test/SKILL.md`).

## Устройство страницы теста

Все тесты построены по одному шаблону; новый удобнее начинать с копии последнего (`History_5_grade/Paragraph_18_Ancient_China.html`):

- В `<style>` — токены цветов на `:root`, тёмная тема дублируется в `@media (prefers-color-scheme: dark){:root:not([data-theme="light"])…}` и `:root[data-theme="dark"]`. Один `<div id="app">`, всё рисует JS через `app.innerHTML`.
- `const IMG = {id: "data:image/jpeg;base64,…"}` — все картинки встроены base64 в одну строку; из-за неё файлы весят сотни КБ – 1,5 МБ. Не читай файл целиком: ищи Grep'ом по именам констант или читай с `offset`.
- Дальше — данные темы массивами объектов: вопрос `{q, a, w:[неверные варианты], e:пояснение}` (имена массивов свои в каждом тесте: `PEOPLE`, `DATES`, `FACTS`, `BOOK`…). Функции `*Qs()` превращают данные в вопросы, `shuffle` перемешивает варианты.
- `BLOCKS` — меню: `{n, title, desc, make}`, где `make()` возвращает список вопросов блока; блок `final` собирает 20 случайных вопросов из всех блоков (срезы `.slice(0,k)` подбираются так, чтобы в сумме было 20). Порядок карточек меню задаётся отдельным списком ключей в `menu()`.
- Вопросы на упорядочивание («Лента времени») — `type:"order"`, ответ — `items.join(" → ")`.
- Лучший результат по блокам хранится в `localStorage` через обёртку `store` с `try/catch`. Ключ должен быть уникальным для теста (`geo-best`, `india17_best`): у информатики ключ `"best"` — общий на весь origin, новый тест не должен его повторять.
- В каждом тесте должна быть ссылка «← Все тесты» на `../index.html`: `<a class="home" href="../index.html">` первой строкой разметки меню в `menu()` и стиль `.home` рядом со стилями `.btn`.

## Проверка

После правки теста или `index.html` запустить скрипт, он выполняет код страниц и проверяет вопросы, блоки, картинки, главную и ключи результатов (нужен только Node):

```bash
node .claude/skills/new-test/check_tests.js
```

Затем открыть `index.html` и изменённый тест в браузере, пройти хотя бы один блок и «Контрольную проверку», посмотреть светлую и тёмную тему и ширину телефона.
