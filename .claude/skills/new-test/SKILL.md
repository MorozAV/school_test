# Новый тест

Устройство страницы описано в разделе «Устройство страницы теста» в `CLAUDE.md`. Здесь только порядок работы и то, что легко забыть.

Механические правила проверяет скрипт. Верность фактов он проверить не может: за неё отвечаешь ты.

## Порядок работы

1. **Прочитай параграф.** Учебник лежит в папке предмета; бери только нужные страницы через скилл `pdf`. Каждый ответ и пояснение должны опираться на текст параграфа, а не на общие знания: даты и написание имён в учебниках расходятся.
2. **Скопируй последний тест этого предмета** в `<Предмет>_5_grade/Paragraph_<N>_<Тема>.html`. Если предмета ещё нет, скопируй `History_5_grade/Paragraph_18_Ancient_China.html`.
3. **Замени в копии всё, что относится к старой теме:**
   - `<title>`, шапку и плашки в `menu()`, текст в `study()`;
   - `IMG` и массивы с данными;
   - `KEY` — новый вида `<тема><параграф>_best`;
   - `BLOCKS`, список ключей в `menu()` и срезы `.slice(0,k)` в блоке `final`, чтобы в сумме вышло 20.
4. **Найди остатки старой темы:** поищи Grep'ом имена и названия из прошлого теста. Скрипт их не заметит.
5. **Добавь карточку** `<article class="test-card">` в `index.html` и поправь счётчик «Доступно N тестов».
6. **Запусти проверку** и исправь все ошибки:

   ```bash
   node .claude/skills/new-test/check_tests.js
   ```

   Код выхода 1 значит, что есть ошибки. Замечание про старую «Ленту времени» в § 4 географии — известное, его можно не трогать.
7. **Проверь в браузере.** Запусти сервер `static` через `preview_start`, затем отдай проверку сабагенту `browser-smoke`. В задаче укажи адрес, что базы нет и что можно нажимать всё. Проверки: один обычный блок, «Лента времени», «Контрольная проверка», светлая и тёмная тема, ширина телефона, ссылка «← Все тесты».
8. **Коммит — только по просьбе.** Сообщение вида `✨Тест по истории 5 класса: § 18 «Древний Китай»`, файлы списком: тест и `index.html`.

## Что скрипт проверяет

| Где | Что |
|---|---|
| Вопросы | есть текст, ответ и пояснение; ответ среди вариантов ровно один раз; варианты не повторяются, в том числе с другим регистром или пробелами; порядок в заданиях «Лента времени» |
| Блоки | все показаны в меню; в контрольной всегда 20 вопросов без повторов; каждый блок попадает в контрольную |
| Страница | ссылка «← Все тесты» и её стиль, тёмная тема, `viewport`, все картинки есть в `IMG` |
| Главная | карточка на каждый тест, ссылки с точным регистром букв (на GitHub Pages он важен), счётчик и слово при нём |
| Все тесты | у каждого свой ключ результатов |

## Частые ошибки

| Ошибка | Как избежать |
|---|---|
| Новых вопросов меньше, чем в копии, и `.slice` просит больше, чем есть | Скрипт покажет «вопросов 19»: поправь срезы |
| Вопрос пропал без следа | Шаблон выбрасывает вопросы с потерянной картинкой; скрипт сообщит «в IMG её нет» |
| Верный ответ заметно длиннее неверных | Выравнивай варианты по длине и стилю |
| Ответ попадает в формулировку другого вопроса | Перечитай блок целиком |
| Пояснение повторяет ответ | Добавляй в него новый факт из параграфа |
